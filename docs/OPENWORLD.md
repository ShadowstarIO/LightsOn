# Outdoors

Separate from venues. Venues stay unranked. Outdoors is a liveliness list so street and moving events can be found.

- A **pocket** is a short range (~20 yalms), not a whole city.
- Timer starts when you enter the pocket. After **~10 minutes**, if you still there and **Note outdoor scenes** is on, LightsOn may file a tier.
- Tiers: extremely busy, some activity, some wandering. Plus an in-character chip.
- Friends / Free Company can be left out of company.
- If most of what you see is friends or Free Company, LightsOn asks **is this a private gathering?**
  - ≥ 33% of LightsOn votes say private, and < 25% say public → hide
  - ≥ 25% say public → list (public wins if both fire)
- Public list is ~20 minutes, hottest first, grouped by world.
