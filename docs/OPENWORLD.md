# Outdoors

Separate from venues. Venues stay unranked. Outdoors is a liveliness list so street and moving events can be found.

- A **pocket** is a short range (~20 yalms), not a whole city.
- **Audit** starts a stay-here watch (about 60 seconds). Busier scenes finish sooner (~15s extremely busy, ~30s some activity). Leave the pocket and it cancels. Note is a button; it does not send itself from Audit.
- Idle path still exists: after **~10 minutes** in the same pocket, if **Note Outdoor Scenes** is on, LightsOn may file a tier.
- The same pocket can be noted again sooner if the scene **got busier**. Same or quieter: wait longer (about 20 / 8 / 3 minutes by last tier).
- Tiers: extremely busy, some activity, some wandering. Plus an in-character chip.
- Friends / Free Company can be left out of company.
- If most of what you see is friends or Free Company, LightsOn asks **is this a private gathering?**
  - ≥ 33% of LightsOn votes say private, and < 25% say public → hide
  - ≥ 25% say public → list (public wins if both fire)
- Public list is **~20 minutes**, hottest first. Zones on the left, pockets on the right. Flag places a map marker on the cell, not a person’s feet.
- Outdoor notes are for the street, not listed plots.
